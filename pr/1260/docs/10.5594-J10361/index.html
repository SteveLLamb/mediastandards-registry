Abstract
Much work has been done, and much has been written in recent years, regarding the use of digital techniques in television. This tutorial paper examines the various A/D and D/A conversion techniques which are applicable to today's and tomorrow's video technology. The dominant error sources associated with each technique are discussed. Test methods and results are described which demonstrate how properly designed conversion systems can be expected to perform in an analog video environment. Where conventional analog test methods may provide ambiguous or misleading results, alternate test methods are proposed.
